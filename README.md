# Supermarket POS Kurdish

Online-only Sorani Kurdish supermarket POS for 2–3 cashiers.

## Architecture
- React + TypeScript + Vite frontend
- Supabase Auth and PostgreSQL cloud database
- Render hosting
- No local database or offline sales
